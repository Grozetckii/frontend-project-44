# Brain games

**Brain games** — это набор консольных мини-игр, созданных для тренировки мозга. Каждая игра задает вопросы, на которые нужно дать правильные ответы.

## Требования к системе

- Unix system (Macos/Linux)
- Nodejs 22.x+
- Make

## Установка

Для локального запуска и тестирования проекта выполните следующие шаги:

1. **Клонируйте репозиторий:**

   ```bash
   git clone https://github.com/Grozetckii/frontend-project-44
   cd frontend-project-44
   ```

2. **Установите зависимости:**

   ```bash
   npm ci
   ```

3. **Свяжите пакет глобально (опционально):**
   ```bash
   npm link
   ```
